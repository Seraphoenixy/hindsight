# [ADR-010] 同名工作区共享项目身份

- 日期：2026-11-26
- 状态：已采纳
- 背景：共享工程库原先对主仓库绝对路径计算八位短码。同名仓库位于不同计算机或目录时得到不同项目身份，导致同步后的项目召回和页面目录分裂。
- 方案：用户负责保证同名工作区等价。项目 ID 取主仓库目录名，经 Unicode NFC、转小写和 URI 编码生成；不包含路径、随机值或哈希，也不截断名称。URI 编码只保护标签和文档 ID 的分隔符。页面目录显示归一化名称，不附带项目短码。
- 影响范围：Coding Agents 共享模式的项目标签、元数据、文档命名空间、默认召回和项目页面。Linked worktree 继续使用主仓库名称；非 Git 工作区优先采用会话根目录名称。
- 与上游差异：保留共享工程库的名称身份约定，后续同步不能重新引入按机器路径隔离的项目短码。
- 验证依据：跨路径同名、长名称、Unicode、分隔符、worktree 与共享页面目录的回归测试。
- 替代关系：替代原有本地路径哈希身份。既有带短码的标签、文档 ID 和页面目录保持原样，历史内容可通过跨项目查询或管理界面访问；本次不执行数据迁移。

## 本地适配

- Windows 工作进程初始化跳过 Linux 专用 resource 导入和内存上限设置，避免 PDF 与 Office 子进程启动即崩溃。
- 公平调度测试显式隔离本分支默认操作并发上限，验证全局队列行为。
- profiling 测试以 UTF-8 读取 Python 源码，避免 Windows 默认 GBK 解码错误。
- 知识库与扩展测试使用确定性记忆嵌入和 RRF 替身；记忆向量维度与测试数据库的 384 维一致，知识库自身使用八维替身。数据库读写、文件处理和搜索流程实际执行。
- 关联文档的召回测试检查前置记忆写入响应，避免将前置写入失败误判为搜索故障。

# Private 分支定制化开发文档

本目录（`hindsight-docs/docs-private/`）用于集中记录 `private` 分支的个人定制化开发设计、改造决策与维护说明，与上游 `docs/` 目录保持物理隔离，避免后续同步或参考上游时产生文档冲突。

## 分支定位与约定

- **`main` 分支**：严格跟随上游仓库，不做个人业务修改。
- **`private` 分支**：以无历史提交的独立起点建立，用于个人定制化功能开发与实验。
- **文档组织方式**：本目录下的所有 `.md` / `.mdx` 文件会自动生成左侧导航栏（通过 `sidebars-private.ts` 的 `autogenerated` 配置），新增文档无需手动维护侧边栏配置。

## 建议记录的内容

- **架构与设计决策**：为什么要做某项定制、与上游方案的差异及取舍。
- **模块改造说明**：改动涉及的核心文件、配置项、数据库迁移或接口变更。
- **上游同步策略**：哪些上游修复需要 cherry-pick 合并，哪些模块已独立演进。
